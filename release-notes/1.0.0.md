## ⚠️ Breaking changes

This release supports Spring Boot 4 only. Spring Boot 3 applications must stay on 0.9.x.

- **Requirements:** Spring Boot 4, Kotlin 2.2 or newer, Jackson 3, Java 17 or newer.
- **TokenService:** `TokenServiceImpl` takes a Jackson 3 `tools.jackson.databind.ObjectMapper`. If your
  application has only a Jackson 2 `ObjectMapper` bean, no `TokenService` bean is created.
- **EncryptionService:** new values are encrypted with AES-GCM. Version 0.9.x cannot decrypt them.
  If 0.9.x and 1.0.x services share encrypted data, upgrade all of them before you write new values.
- **FixtureHelper:** now uses Fixture Monkey. Replace `fixture<T>()` with `fixture.giveMeOne<T>()`.
  Replace `before`/`after`/`between` with `FixtureHelper.instantBefore`/`instantAfter`/`instantBetween`.
- **Reactor extensions:** the `Mono`/`Flux` extension functions now require `T : Any`.

## 🔐 Security cautions

- `box.libs.utilities.security.crypto.key` must be a long random secret, not a human password.
  The AES key is derived with PBKDF2-HMAC-SHA256 at 1,024 iterations, which is fast but gives
  little protection for a weak key.
- Values in the old AES-CBC format still decrypt, but that format is not authenticated.
  Re-encrypt your stored values (decrypt, then encrypt again). Then set
  `box.libs.utilities.security.crypto.legacy-cbc-decryption-enabled=false`.

## Other changes

- `jjwt-impl` is included. Remove it from your application dependencies.
- Spring Framework 7.0, Reactor 3.8, Spring Security 7.1, Micrometer 1.17, gRPC 1.83, JJWT 0.13.

See the README section "Migrating from 0.9.x (Spring Boot 3) to 1.0.x (Spring Boot 4)".
